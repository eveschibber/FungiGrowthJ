Overview

1. Introduction

FungiGrowthJ is a Fiji/ImageJ workflow for organizing, detecting, reviewing, measuring, and exporting fungal colony observations from digital Petri-dish photographs. It is designed for longitudinal experiments in which the same biological replicate is photographed on multiple dates.

The software deliberately separates automated image processing from scientific review. FungiGrowthJ can propose agar boundaries, colony objects, and central/satellite classifications, but the user retains control over decisions that affect the scientific result.

Core principle: automate repetitive image processing without hiding methodological decisions. Critical operations remain visible, editable, and traceable in the exported results.

Single Image

Complete analysis of one photograph, including calibration, agar selection, detection, review, manual correction, and export.

Experiment / Batch

Processes a structured experiment across strains, replicates, and dates while persisting status, failures, review states, and results.

Acquisition

3. Image requirements and acquisition

FungiGrowthJ is designed for photographs in which the colony boundaries can be segmented from the surrounding agar and, in the current workflow, are commonly represented by dark marker contours.

Recommended

  • Same camera and resolution through a longitudinal experiment whenever possible.
  • Stable plate positioning and lighting.
  • High enough contrast to distinguish marker contours from agar.
  • Minimal glare and reflections.
  • Original files retained without overwriting.

Avoid

  • Strong shadows crossing the plate.
  • Large reflections inside the agar region.
  • Unknown changes in zoom or camera geometry without recalibration.
  • Heavy compression when the marker boundary is already faint.
  • Multiple images in one date folder when the experiment expects one image per date.
Missing image is not zero growth. An absent photograph is an unavailable observation, not evidence that colony area was zero.

Step 1

7. Spatial calibration

Spatial calibration converts image measurements from pixels into a physical unit. Without a valid calibration, the image still contains useful raw geometry, but physical values such as area_mm2 and perimeter_mm cannot be interpreted in millimetres.

Batch calibration policies

PolicyBehaviorUse when
Global calibration for entire experimentThe first accepted calibration is reused for subsequent images.Image geometry and acquisition settings are stable.
Recalibrate every imageEvery photograph gets a new line calibration.Resolution, camera height, zoom, or framing can vary.
Ask before each imageAllows the user to decide whether to reuse or recalibrate at each image.Mixed acquisition conditions.

Procedure

  1. Select Fiji's Straight Line tool.
  2. Draw the line over a known distance.
  3. Enter the known value and unit.
  4. Prefer a relatively long known distance, such as 10–20 mm, when available, to reduce relative endpoint-placement error.
pixels_per_unit = line_length_px / known_distance
unit_per_pixel = known_distance / line_length_px
Do not treat a line calibration as transferable across images when the image geometry can change.
Step 2

8. Select a representative agar sample

The agar sample is a local reference for the current photograph. It is not a biological measurement and it should not be selected from a colony, marker trace, strong reflection, or edge artifact.

Select

  • clean agar;
  • representative illumination;
  • away from colonies;
  • away from black marker;
  • away from bubbles and strong reflections;
  • inside the useful agar region.

FungiGrowthJ uses the average RGB appearance of this sample as the basis for color-similarity detection of the agar region.

Practical rule: when the agar ROI is difficult to obtain even after adjusting the main tolerance parameter, select a better agar sample rather than forcing several morphological sliders to extreme values.
Step 3

9. Agar ROI detection and adjustment

The interactive agar screen estimates the useful plate region and allows controlled adjustment before colony detection begins.

The accepted agar ROI should follow the usable agar region, not the outer glass edge.

A slightly imperfect image should not be “rescued” by extreme slider values. Re-select the sample when the underlying color reference is poor.
Optional spatial reference

10. Inoculation origin

When enabled, the user marks the actual inoculation point in the current photograph. This provides a biological reference for spatial distribution that is often more meaningful than the geometric center of the plate.

Procedure

  1. Select the Point tool.
  2. Click the visible inoculation origin in the current image.
  3. Confirm the point.

The recorded position can be used to calculate distance_to_inoculation_origin_mm and angle_from_inoculation_origin_deg for detected colonies.

Per-image reference: the inoculation origin is marked separately in each image. Do not assume that the same pixel coordinate remains valid if the plate moves or rotates between dates.

Segmentation

12. Detection mask and preprocessing

Within the confirmed agar ROI, FungiGrowthJ builds a binary detection mask from the image signal. The mask represents the regions that will be considered during object detection and can be further refined before candidate extraction.

RGB image
↓
Brightness / thresholding context
↓
Binary detection mask
↓
Binary closing
↓
Optional gap closure
↓
Fill holes
↓
Particle/candidate detection

Automatic illumination handling

The current workflow evaluates broad, low-frequency brightness variation and applies correction only when a substantial illumination gradient is detected. This is intended to reduce false segmentation caused by uneven illumination without changing the original image.

Marker gap closure

The parameter Marker gap closure iterations is a conservative correction for short interruptions in dark contours before Fill Holes. It is useful when the experimental boundary is represented by a dark trace; the underlying detection mask remains a general-purpose binary mask that can also be edited or masked elsewhere.

Closing vs marker-gap closure: general binary closing and marker-gap closure serve related but distinct purposes. Marker-gap closure is a targeted correction for small dark-trace gaps.
Manual correction

13. Manual dark-artifact cleaning

When the image contains dark dots, stains, dust, annotations, or other non-marker structures that pass thresholding, the detection mask can be cleaned before candidate detection.

Procedure

  1. Enable Clean dark artifacts manually before detection.
  2. FungiGrowthJ displays the binary mask used for detection.
  3. Use the Paintbrush with black to erase white mask regions that correspond to unwanted dark artifacts.
  4. Do not edit the source photograph.
  5. Close/accept the cleaned mask so subsequent detection uses the corrected mask.

The manual eraser changes the binary detection mask only. The original photograph remains unchanged.

Best practice: erase only clearly identifiable artifacts. Irregularity by itself is not evidence of an artifact: real colonies can have irregular boundaries.

Audit

Where supported, the cleaned detection mask can be retained as dark_artifact_cleanup_mask.tif so the intervention is inspectable.

Connected objects

14. Touching-colony partition

Two or more nearby colonies can remain connected after the marker is thresholded. The current workflow includes Enhanced touching-colony partition to recover separate regions when the geometric evidence is adequate.

How it works conceptually

The routine searches for enclosed internal structures within a connected candidate and can use these to create independent ROIs. The user can then review the resulting proposals.

Parameter

Minimum enclosed interior area defines how small an interior structure can be before it is ignored by the partition routine. The current default is 150 px².

Automatic partition is a proposal, not a biological decision. Always review the resulting ROIs before export.
Object detection

15. Colony detection

After preprocessing, Fiji/ImageJ converts closed contours into candidate ROIs and calculates the initial measurements used by the review interface.

Initial measurements

  • area;
  • perimeter;
  • centroid;
  • circularity;
  • position relative to the agar center;
  • ellipse/Feret geometry;
  • shape metrics such as solidity and convexity.

Automatic central/satellite proposal

The object closest to the geometric center of the agar is proposed as the central colony. Other candidates are proposed as satellites. This proposal is intentionally revisable.

Central is not the same as green. Review colors indicate visual/review state. Green acceptance does not by itself mean that an object is the central colony.

Alerts

AlertMeaning
LOW_CIRCLow circularity before editing.
LOW_CIRC_EDITLow circularity after editing.
NEAR_EDGEObject is near the agar boundary.
AREA_OUTLIERUnusual object area.

Low circularity is a review flag, not an automatic rejection criterion. A biologically real colony may be elongated or irregular.

Manual geometry

17. Edit / replace ROI

Edit an existing ROI

When the automatic contour is close but not correct, the user can modify the ROI with standard Fiji selection tools.

  1. Select the ROI in ROI Manager.
  2. Edit the shape with Fiji's ROI tools.
  3. Use Update in ROI Manager.
  4. Mark the ROI as manually edited when requested by the workflow.
  5. Recalculate/confirm the object so exported measurements correspond to the edited ROI.

Replace the automatic ROI completely

Use Replace with manual ROI when the automatic contour is not a suitable starting point.

  1. Choose a closed area-selection tool in Fiji.
  2. Draw or construct the final biological area occupied by the colony.
  3. If the colony contains holes, subtract those regions using Fiji selection operations so the final ROI can be composite.
  4. Leave the finished ROI active on the image.
  5. Press Use manual ROI.
  6. Review the resulting measurements and classification again.

FungiGrowthJ measures the replacement ROI and records the intervention, including edited_manually = true and edit_operation = ROI_MANUAL_REPLACE.

A manual replacement should trace the biological region, not the glass edge or a convenient geometric approximation.
Manual correction

18. Cut / Trim ROI

Cut / Trim ROI is used when the automatically detected outer contour is basically correct, but one or more unwanted connections or protruding regions must be removed.

When to prefer Cut / Trim

  • The outer automatic boundary is good.
  • Only a connection between regions needs to be severed.
  • An unwanted attached fragment should be removed without redrawing the entire colony.

How the cut is drawn

The current implementation accepts straight, segmented, and freehand line ROIs. FungiGrowthJ does not change the currently selected Fiji line tool.

  1. Choose Cut / trim automatic ROI from the review action menu.
  2. Draw one line across the connection or unwanted region.
  3. Extend the stroke completely across the connection you want to separate.
  4. Press Apply this cut.
  5. Repeat with additional cuts as needed. There is no preset maximum number of cuts.

The cut is converted to a narrow strip and subtracted from the current shape. The original outer contour is otherwise preserved.

After applying a cut

ActionMeaning
Draw another cutAdd another separation.
Preview resulting regionsSplit the current shape into disconnected fragments and review them.
Undo last cutRestore the previous geometry.
Cancel correctionAbort the cut correction.

Reviewing cut regions

FungiGrowthJ reviews the resulting fragments one at a time. The active fragment is highlighted in red and the other fragments receive thin cyan outlines.

For each fragment, choose:

  • Keep as colony — keep it as a biological region.
  • Discard — remove it from the resulting colony set.

The safe default is Keep as colony. This is intentional: the user must explicitly discard non-biological fragments.

Navigation during cut review

  • Save and next region.
  • Previous region.
  • Return to cuts.
  • Cancel correction.

Cut review summary

The summary displays the number of generated regions, the number kept, and the number discarded. Kept regions are shown in green and discarded regions in gray.

The user may then accept the result, review the regions again, add another cut, undo the last cut, or cancel.

If a cut does not separate the object: the line probably did not cross the complete connection. Extend the cut, add another cut, or undo the last cut. Do not assume that one partial stroke should automatically create two biological colonies.
Multiple colonies

19. Split ROI into multiple colonies

Split ROI into multiple colonies is used when one detected object contains several colonies and the user needs to define the child ROIs explicitly.

Procedure

  1. Choose Split ROI into multiple colonies.
  2. Specify how many colonies are present.
  3. Draw each child ROI in sequence.
  4. Review the child measurements shown by the split preview.
  5. Confirm the complete set.

The current workflow allows up to 10 daughter colonies in one split operation for quality control. A further split can be applied to any child ROI that still contains multiple colonies.

Traceability

Child objects retain their relationship to the original object through parent/child identifiers and the split operation. New split ROIs are highlighted in cyan during the review process.

Split vs Cut: Cut / Trim removes a narrow strip from an existing shape and then asks the user which resulting fragments to keep. Split ROI asks the user to explicitly draw the daughter colony regions.
Low-confidence detection

20. Very small / point-like candidates

The normal candidate detector uses a minimum object area. When very small colonies may be biologically relevant, the user can enable Detect very small / point-like colony candidates.

This produces a second, low-confidence candidate pass. These candidates are never silently auto-accepted; they are explicitly sent to review.

The current default minimum for this pass is 20 px².

Very small candidates can also be artifacts, dirt, marker fragments, or text. Their low area is a reason for closer review, not evidence of biological identity.

Restart behavior

Batch is designed to allow the user to stop between images. Completed observations should not be silently reprocessed merely because the session was restarted.

REVIEW and ERROR are not equivalent to successful analysis. A result from an observation with unresolved failure/review state should not be treated as a completed scientific observation without verification.

Visual review of REVIEW / ERROR observations

When persisted ROIs/results exist, Batch can be used to inspect the image and decide whether the observation can be closed as completed or should remain under review. Changing a workflow status is not the same as re-running the entire image analysis.

24. Complete output-variable glossary

The CSV is an object-level table: each row represents one detected, reviewed, edited, split, or otherwise retained ROI record from one image. The fields below explain exactly what each variable means and, for categorical fields, which values FungiGrowthJ can export.

Important distinction: final_type is the field that identifies what the object is for biological use. review_status, review_flag, review_code, review_note, and edit_operation describe how the object was processed or reviewed. They are traceability fields, not interchangeable biological classifications.

25. Formulas and biological interpretation

Area-equivalent radius

r_eq = sqrt(A / π)

Useful as a scalar linear descriptor of irregular colony size. It is not a geometric radius from an observed center.

Area expansion rate

area_rate = (A_t2 - A_t1) / Δt

Describes observed change in visible colony area per unit time over the interval considered.

Equivalent radial expansion

radial_rate = (r_eq,t2 - r_eq,t1) / Δt

Describes change in the area-equivalent radius through time.

Aspect ratio

AR = major_axis / minor_axis

Eccentricity

e = sqrt(1 - minor_axis² / major_axis²)

Circularity

Circularity = 4πA / P²

Solidity

Solidity = A / A_convex_hull

Centroid-to-centroid distance

d = sqrt((x_sat - x_cen)² + (y_sat - y_cen)²)

Inoculation-origin distance

d = sqrt((x_col - x_inoc)² + (y_col - y_inoc)²)
These formulas describe image geometry. They do not by themselves establish biological mechanisms such as sporulation, spore dispersal, biomass production, or growth physiology.

28. Troubleshooting

ProblemLikely causeAction
Agar ROI will not fit the platePoor agar sample or very different local appearance.Reselect the agar sample before using extreme morphology settings.
Too much background enters the agar ROIRGB color tolerance too high.Reduce tolerance; if necessary, select a better sample.
Agar is missing from the ROITolerance too low, strong shadow/reflection, or poor sample.Increase tolerance first; reselect the sample if needed.
Marker lines have small breaksContour interruption before Fill Holes.Try a small value for Marker gap closure iterations and inspect the mask.
Many dark dots/stains are detectedDark artifacts pass threshold.Use manual dark-artifact cleaning and erase only obvious artifacts from the binary mask.
Two colonies are detected as one objectContours remained connected.Enable Enhanced touching-colony partition, use Cut / Trim, or Split ROI.
One cut does not separate the objectThe stroke did not cross the complete connection.Extend the cut across the connection, add another cut, or undo the last cut.
Cut creates a small non-biological fragmentThe cut removed an attached artifact or contour piece.During fragment review, explicitly choose Discard for the non-biological region.
Automatic central proposal is wrongProposal is based on position relative to plate center.Explicitly classify the correct ROI as central during review.
Text/letters become candidatesDark structures legitimately pass threshold.Review and classify them as IGN when appropriate.
Very small objects are missedBelow the normal minimum candidate area.Enable the very-small candidate pass and review all resulting candidates.
Batch observation is in ERRORWorkflow did not finish successfully.Do not treat it as completed. Review the image/log or re-run only if necessary.
Batch observation is in REVIEWHuman decision remains unresolved.Use visual review, confirm the persisted result, and explicitly close or retain the review state.

Final checklist

29. Reproducibility and traceability

For a reproducible experiment, retain the following together:

  • Original source images.
  • The exact FungiGrowthJ version(s).
  • Calibration policy and calibration values.
  • Agar-sample and agar-ROI decisions.
  • Detection settings relevant to difficult images.
  • Manual artifact cleanup when used.
  • Partition/Cut / Trim/Split interventions.
  • Review classifications.
  • Parent/child identifiers and edit operations.
  • Batch state and logs.
  • Final result CSV files.
